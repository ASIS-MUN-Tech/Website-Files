# ASIS MUN 2026 Website

This is the updated GitHub-ready website package for ASIS Model United Nations 2026.

## Included pages and files

- `index.html` — Home page
- `about.html` — About page
- `committees.html` — Committees and agendas
- `secretariat.html` — Secretariat page
- `resources.html` — Delegate resources and training information
- `faq.html` — Frequently asked questions
- `contact.html` — Contact page
- `register.html` — Registration page
- `styles.css` — Desktop and mobile styling
- `script.js` — Navigation, committees, FAQs and interactions
- `assets/` — School logo and website images

## Latest mobile fixes

- The mobile-menu close icon is fully visible and centred.
- Opening the mobile menu locks the underlying page.
- Scrolling inside the menu does not move the website behind it.
- Closing the menu restores the visitor's previous page position.

## Replacing an existing GitHub version

1. Open the GitHub repository.
2. Delete the existing website files, but do not delete the repository itself.
3. Extract this ZIP on your device.
4. Open the `ASIS-MUN-Website-Updated` folder.
5. Upload everything inside that folder to the repository root.
6. Confirm that `index.html` is visible in the root of the repository.
7. Commit the upload.

If GitHub Pages or Cloudflare Pages is already connected to the repository, the updated website should redeploy automatically after the commit.

## Editing guide

- Edit page wording inside the relevant `.html` file.
- Edit colours, spacing or responsive design in `styles.css`.
- Edit navigation, committee details and FAQs in `script.js`.
- Add or replace images inside the `assets` folder.
